The first release of Tape, a desktop trading client for Interactive Brokers that connects to TWS or IB Gateway through the API port. Tape never asks for or stores your IBKR credentials.

- **Portfolio**: account summary, positions, working orders and today's trades.
- **Trade**: charts with indicators, an order ticket with bracket and conditional orders, Level 2 book, and option chains with volatility and positioning (GEX, open interest).
- **Watchlists and alerts**: price, indicator and news alerts, delivered as system notifications.
- **Safety**: every order is reviewed before it is sent; Cancel all is confirmed in two steps; a PIN / Touch ID lock screen.
- **Your data stays local**: watchlists, alerts and notifications live in a folder you choose, one subfolder per IB account.
- English and 中文, light and dark themes.

Tape updates itself from this page: Settings › About.

**Install**: download `Tape-1.0.0-arm64.dmg` (Apple Silicon, macOS), open it and drag Tape to Applications.

Tape 首个版本：一款连接 TWS / IB Gateway 的盈透证券桌面交易客户端，不会询问或保存你的 IBKR 账号密码。

- **组合**：账户概览、持仓、挂单与当日成交。
- **交易**：带指标的图表，支持括号单与条件单的下单面板，Level 2 盘口，期权链及波动率与持仓分析（GEX、未平仓量）。
- **自选与提醒**：价格、指标与新闻提醒，以系统通知送达。
- **安全**：每笔订单发送前均需确认；全部撤单需两步确认；PIN / Touch ID 锁屏。
- **数据留在本地**：自选、提醒与通知保存在你选择的文件夹中，每个 IB 账户一个子文件夹。
- 支持英文与中文、浅色与深色主题。

Tape 会从这里自动更新：设置 › 关于。

**安装**：下载 `Tape-1.0.0-arm64.dmg`（Apple 芯片 Mac），打开后将 Tape 拖入“应用程序”。
